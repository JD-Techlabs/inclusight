Methodology

Automated testing: each platform in scope was crawled and every page was tested with axe-core and the Inclusight custom rules, on desktop and mobile screen sizes. Identical issues on pages built from the same template were grouped into one finding.

Manual testing: criteria that automated checks cannot decide were tested by hand using the Inclusight test procedures (keyboard-only use, screen readers, zoom and reflow, captions, forms and error handling), with a result, notes and evidence recorded for each criterion.
